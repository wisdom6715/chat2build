# Chat2Build Bootcamp

A componentized Next.js + TypeScript + Tailwind CSS landing page based on the supplied Chat2Build reference.

## Structure

- `app/page.tsx` — page composition
- `app/components/site.tsx` — reusable header, hero, content sections, FAQ accordion, CTA, and footer components
- `app/globals.css` — Tailwind layers and design tokens
- `public/manus-routes.json` — managed preview route manifest

## Run

```bash
npm install
npm run dev
```
